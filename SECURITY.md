# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use the "Report a vulnerability" button on the Security tab of this repository instead, which reaches the maintainers privately.

We will acknowledge your report within three working days and keep you informed until the problem is fixed.

## Supported versions

There are no releases. Fixes are made on the `main` branch, so run the latest commit of `main`.
